# Editors

## [Visual Studio Code](https://code.visualstudio.com/download)

### Installation

Just follow the [Visual Studio Code](https://code.visualstudio.com/download) to download the editor

It's used to code projects:

- Go
- NodeJS

### Install Extensions

To have the same formatting for all developers, we need to install the extensions

1. Required extensions

- [Tailwind Css IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss). Useful for tailwind styles highlighting hint

![Tailwind Css IntelliSense](./img/tailwind-css-intellisense.png)

- [Prettier - Code formatter](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode). Format code properly

![Prettier](./img/prettier.png)

2. Optional extensions

- [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)

![ESLint](./img/eslint.png)

- [Auto Rename Tag](https://marketplace.visualstudio.com/items?itemName=formulahendry.auto-rename-tag)

![Auto Rename Tag](./img/auto-rename-tag.png)
